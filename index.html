For the whole squadron, do it in the file instead. What you type here applies to this browser only — useful for testing, but it would mean every cadet setting up their own. To connect the site once for everyone, put the same two values into hub-config.js and re-publish.
ONE-TIME SETUP
  1. Create a free project at supabase.com — choose the London (eu-west-2) region.
  2. Open the SQL Editor, paste in the whole of hub-schema.sql, and run it.
  3. Go to Project Settings › API and copy the two values below.
  4. Follow the note at the bottom of the SQL file to make yourself the first staff account.
In Supabase this is under Project Settings › API Keys, labelled Publishable key — the one it says is safe to share. It names your project; it does not grant access. What protects the data is the security rules in the SQL file.
Never paste a secret key here. Secret keys ignore the security rules, so putting one in a web page would expose every cadet’s record to anyone who looked. The hub will refuse one.
